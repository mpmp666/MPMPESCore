# 26.2 生物行为与附魔改进

本次以用户提供的 MCP-Reborn 26.2 源码和其内嵌资源数据为参考，修改 MPMPESCore 的现有生物与附魔系统。**现有 26 类生物都已接入共享控制器，但这仍是旧 MCPE 协议与物理系统下的适配，不是完整现代 Java 服务端。**

## 生物行为

- 原有多个定时器分别改位置的 AI 改为统一 tick；修复生命/火焰/空气/年龄重复更新，地面移动使用碰撞与重力，保留受击击退。
- 已加入有界路径搜索、绕障碍、实际碰撞体与头顶空间、一步跳跃/安全落差、水中浮起、水生/飞行模式，以及真正受遮挡影响的视线。
- 僵尸/僵尸村民会寻找玩家、村民和铁傀儡，白天检查真实遮顶与头盔；骷髅使用真实箭实体并有射击间隔。
- 苦力怕按 3 格开始、7 格内保持、失去视线/距离时回退的蓄爆条件运行，30 tick 引爆；仍受原有爆炸保护事件和配置控制。
- 僵尸猪人和狼采用中立/受击仇恨及同伴警戒；驯服狼保存主人，可空手右键切换坐下/跟随，肉类恢复和繁殖另行处理。
- 被动动物支持正确食物引诱、受击恐慌、喂食求爱、60 tick 求偶、幼崽成长/跟随、父母 6,000 tick 冷却。仅靠近或拿着食物不会自动繁殖。
- 羊吃草后恢复羊毛，成年鸡按 6,000–12,000 tick 下蛋；蜘蛛有遮光索敌与攀爬冲量，洞穴蜘蛛接受命中后才施毒；史莱姆按体型计算伤害。
- 末影人支持注视/南瓜头/视线判定、受击仇恨、避水与受限安全传送；烈焰人与恶魂有蓄力、投射物和冷却。
- 修正当前实体的碰撞宽高、眼高、基础生命和耐火属性；幼崽成长时同步更新碰撞体。
- 导航、感知和生物投射物只使用当前已加载区块，不为寻找目标或走路生成新地形；状态缓存和搜索节点数量均有界。

覆盖：牛、哞菇、猪、羊、鸡、兔、狼、豹猫、村民、铁傀儡、雪傀儡、僵尸、僵尸村民、僵尸猪人、骷髅、蜘蛛、洞穴蜘蛛、苦力怕、史莱姆、岩浆怪、蠹虫、末影人、烈焰人、恶魂、蝙蝠、鱿鱼。

**尚未完整实现：** 村民现代 Brain/床/职业工作点/日程/交易，现代狼狩猎与主人完整战斗历史，史莱姆分裂与完整跳跃节律，蠹虫入方块，僵尸增援/转化/破门，末影人搬方块及原版弹射物免疫，蝙蝠/鱿鱼/雪傀儡全部环境细节等。火球在服务端是有归属、碰撞与伤害的投射物，旧客户端显示为带火焰的雪球模型；没有使用 TNT 替代。完整类别与遗漏见 `AI_26_2.md`。

## 附魔规则和获取

保留旧版已知附魔 ID **0～24**，不把现代新附魔硬塞进未知协议编号。

- 按 26.2 修正最高等级、权重、附魔能力区间、装备槽位、物品适用范围与互斥组。
- 附魔台采用带种子的 JavaRandom 生成，显示所需等级与实际支付 1/2/3 级、1/2/3 青金石分开处理；创造模式不扣资源。普通书可转为附魔书。
- 附魔种子在同一玩家关闭/重开菜单时保留，成功附魔后刷新。服务端核对物品和书架快照、选项、完整结果及资源，拒绝伪造成品和重放。
- 铁砧支持材料修理、同物品合并、同级附魔升一级、等级上限、冲突、改名与累计惩罚；修理惩罚按 1/3/7/15/31 递增，一般生存操作达到 40 级拒绝，纯改名费用上限 39。
- 铁砧输出由服务端算价、扣费并保存为已支付结果，只能领取一次。旧客户端省略的 RepairCost 由服务端补齐，明确篡改的字段仍拒绝。未付费结果不能直接写入输出槽。

```text
/enchant Steve minecraft:sharpness 5
/enchant Steve unbreaking 3
/enchant Steve respiration 3
```

命令检查手持物品、合法等级和冲突；例如呼吸只能正常附在头盔/书上，不能附到靴子上。管理员或插件原有不受限 NBT/setLevel 入口仍可用，正常获取流程会验证。

## 已修复的实际效果

- 锋利的额外伤害为 `0.5×(等级+1)`，亡灵杀手/节肢杀手识别对应生物；伤害取消、无敌帧拒绝或零伤害时不附带点火/击退/荆棘等效果。
- 保护按全部穿戴装备相加，EPF 上限 20，每点减伤 4%；修复原来只取最大值和倍率不正确的问题。
- 呼吸只读取有效头盔，水下速掘影响水下挖掘惩罚；效率按有效工具基础速度加 `等级²+1`，不会让错误工具得到同等效率。
- 耐久按每个损耗点独立判定；工具损耗概率 `1/(等级+1)`，护甲为 `0.6+0.4/(等级+1)`。
- 弓的力量、冲击、火矢、无限和独立暴击伤害已接入；无限/创造的箭不能作为普通箭无限拾取。
- 精准采集与时运按支持的方块掉落处理，不对金块、钻石块等存储方块统一增产；抢夺不会增加玩家装备或任意贵重物品数量。
- 修复钓鱼收杆入口与钓竿注册/耐久，钓饵缩短等待，海之眷顾改变垃圾/宝藏/鱼的权重并考虑开阔水域。
- 深海探索者通过现有移动速度属性适配，水中生效、出水恢复；这是旧客户端移动模型适配，不是 Java 原版水阻力模型。
- 附魔 NBT 更新保留自定义数据，规范数值 ID，防止重复同 ID 条目和字符串 ID 伪装。

旧客户端仍缺少现代附魔、新物品和完整界面。钓鱼宝藏使用可表示的旧版物品子集；普通生物没有统一护甲背包，护甲附魔主要对 Human/Player 体系生效。真实 MCPE 客户端的菜单显示、取出顺序、移动手感尚未逐版本真机验证。

## 配置与运行

`genisys.yml` 的 `ai.enable: true` 已开启。旧生物开关继续生效，新增类别也可单独关闭。`ai.mob-griefing` 控制吃草等地形修改，默认 false；原有 `creeper-explode-destroy-block` 继续控制爆炸破坏方块。旧刷怪入口仍保留，其数量/亮度/生态分布不等于 26.2 的完整自然刷怪系统。

默认末地仍是 `ender`，已有地图不会重建。升级前请备份自己的地图、玩家数据和配置；这些运行时文件和备份不在源码仓库内。
