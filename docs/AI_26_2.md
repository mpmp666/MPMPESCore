# Shared mob AI inspired by Minecraft 26.2

The legacy server now has one controller for all 26 existing concrete mob classes. This is an adaptation of selected Java 26.2 goals to the old MCPE entity protocol, world height, item IDs, collision shapes and integer health model. All existing mobs are covered; full Java 26.2 behavior equivalence is not claimed. Modern mob classes absent from this server are not added.

## Entry points and lifecycle

`pocketmine\entity\ai\VanillaAI26` exposes:

```php
public static function tick(Creature $mob, int $delta = 1): void;
public static function onDamage(Creature $mob, EntityDamageEvent $source): void;
public static function forget(Entity $mob): void;
public static function save(Creature $mob): void;
public static function feed(Creature $mob, Player $player, Item $item): bool;
public static function interactOwned(Creature $mob, Player $player, Item $item): bool;
public static function supports(Creature $mob): bool;
public static function mode(Creature $mob): string;
public static function configKey(Creature $mob): string;
public static function snapshot($id = null): array;
```

Creature calls `tick` once before its movement step; `onDamage` runs after damage cancellation is final. Death/close calls `forget`, and save calls `save` to flush current scalar counters before serializing NBT. Humans and players never enter the mob controller. Existing plugin subclasses of a supported mob inherit the nearest recognized species profile.

The approved right-click hook calls `interactOwned` first for an owned wolf's nonfood sit/release command; this consumes nothing. `feed` returns true when one food/bone was handled; its caller consumes exactly one item in survival. It never removes inventory items internally. Holding food alone only tempts and never creates love.

The controller uses the server tick for cadence, ignores repeated calls during the same tick, and clamps each elapsed update to 1–20 ticks. Target scans run every ten ticks. Each mob keeps a scalar-only record: IDs, positions, counters and string identities; no mob/player/level/chunk object is retained. Records are capped at 4,096, pruned after 1,200 ticks of inactivity, and removed explicitly on close. Target IDs are resolved in the current level on each use. Owner and anger player names, age/love, sheep wool and egg timer persist in NBT. Anger targeting for nonplayer attackers is session-local.

## Old item IDs

- Cow/Mooshroom/Sheep: wheat `296`.
- Pig: carrot `391`, potato `392`, beetroot `457`; carrot-on-stick `398` tempts but is not breeding food.
- Chicken: wheat seeds `295`, pumpkin seeds `361`, melon seeds `362`, beetroot seeds `458`.
- Rabbit: carrot `391`, golden carrot `396`, dandelion `37`.
- Ocelot: raw fish `349`, raw salmon `460`.
- Wolf: bone `352` for taming; raw/cooked pork, beef, chicken, rabbit, mutton and rotten flesh for meat healing/breeding. These are the legacy IDs; modern item tags cannot be copied numerically.

Babies start at `Age=-24000` (20 minutes), feeding advances remaining growth by ten percent, and adults get `Age=6000` after successful breeding. Both adults must have positive real love counters; neither proximity nor merely holding food produces a child. New children use the existing entity factory and a loaded safe position.

## Navigation, limits and protection

Ground movement passes motion intent to Navigation26 and uses Creature collision/gravity/friction. It never uses position teleports for walking. `flying` and `swimming` select their corresponding motor modes. Enderman teleport is exceptional: at most sixteen destination attempts, supported full footprint, no fluid/hazard/body collision, loaded path/chunk checks before and after the cancellable teleport event.

All controller environment queries use only Level's current `getChunks()` map. `getChunk(..., false)` and even `isChunkLoaded()` are unsuitable as no-load guards here: they may consult/load the provider. Unknown blocks are unknown, never air. Queries are capped at 64 blocks, 512 inspected nearby entities and 256 retained candidates. Long paths are handled in bounded navigation windows. Ghast's source 100-block follow range is deliberately capped at 64.

Melee uses EntityDamageByEntityEvent and spends its attack cooldown even if cancelled. Projectile firing uses EntityShootBowEvent where applicable and ProjectileLaunchEvent. Projectile collision uses the existing damage pipeline. Peaceful stops monster acquisition/attacks, and creative/spectator/dead/offline/wrong-level targets are rejected. Existing targets are revalidated before attack.

Creeper and large fireball explosions include the real entity and level in EntityExplodeEvent. `aiConfig['creeperexplode']` controls terrain destruction; with false, entity effects still go through the normal cancellable explosion event. The controller preflights the blast and the legacy entity-query chunk rectangle before invoking Explosion, including its inclusive upper-chunk rounding. `mobgriefing` is optional and defaults false for grazing terrain mutation.

Existing per-species AI flags continue to work. `zombie-follow-range` is clamped to 1–64; `zombie-speed-multiplier` is clamped to 0.1–3. Disabling the controller does not remove the entity's normal environmental/physics tick.

## Explicit adaptations and omissions

- Villager 26.2 Brain memories, POIs, beds, work sites, schedules, gossip, trading, raids and village defense coordination are unavailable. Villagers here have the idle/flee subset above, not a recreated modern Brain. Door opening/breaking remains unavailable; navigation treats closed doors as obstacles.
- Fireball26 is a real server Projectile with owner attribution, damage, combustion, lifetime/boundary checks and large impact explosion. It registers with textual save ID and `NETWORK_ID=-1` to preserve numeric Snowball mapping. Clients see the known snowball model (`81`) with fire metadata. Native fireball visuals, acceleration, spread and player reflection are not implemented; it never uses primed TNT as a substitute.
- Modern wolf hunting/owner combat history, prey ecology, llama avoidance, full tame particles, modern ocelot trust presentation, and cat variants are incomplete. Owner follow, sit/release, meat feed and same-owner protection are the supported subset. Owners persist by case-insensitive player name, not Java UUID.
- Slime splitting on death, full idle hopping rhythm, magma cube size-dependent jump timing and modern collision/contact scheduling are omitted. Combat hops and size damage are adapted to the old motor.
- Enderman block carrying and every modern damage avoidance exception are omitted. Projectile teleport happens after accepted legacy damage; it does not reproduce Java projectile immunity. Daylight teleport probability/cadence and destination attempts are bounded adaptations.
- Snow trails, snow golem biome melting/water rules, bat random ceiling acquisition, advanced squid ink visuals, chicken jockey rules, rabbit crop raiding/killer type, silverfish infested-block behavior, zombie reinforcements/conversion/door breaking, jockeys and equipment AI are not implemented by this controller.
- Spider brightness decisions use day/actual shelter rather than modern light-dependent targeting thresholds. The climb impulse, animal speeds, look turn rate and movement attributes are adapted to the legacy collider/motor. No full Java pathfinder/physics equivalence is claimed.
- Head equipment suppresses sunlight through supported inventory/NBT data; modern equipment wear, rain/powder snow/environment attributes are incomplete. Iron golem damage is rounded to the server's integer-health representation.
- The old protocol cannot display every modern activity animation/metadata field. Sheep wool state and supported baby flags are real legacy metadata; modern Brain displays are not fabricated.

## Verification

Run with a provisioned PHP 8.4 ZTS runtime (bin/ is not included):

```sh
bin/php7/bin/php tools/test_mob_behavior26.php
bin/php7/bin/php tools/test_navigation26.php
```

The controller test executes the real VanillaAI26, MobBehavior26, MobState26, Environment26, Navigation26, event, item and block code against in-memory Entity/Level doubles. It checks 55 behavior assertions: species coverage/human exclusion; creative/spectator exclusion; server-tick and attack cooldown; cancelled damage; collider LOS; peaceful; neutral retaliation, pack and persisted anger; owner immunity/sit/release/save; golem creeper exclusion; exact fuse start/retention/decay/30-tick event and cancellation; no proximity breeding; food/courtship/baby/cooldown; panic/tempt; roof and helmet sunlight; buoyancy; egg timer; unloaded boundary/cleanup; and Blaze/Ghast projectile charge/cooldown. The world fixture throws if controller/navigation calls chunk-loading APIs. This test does not substitute for client rendering or live projectile collision verification.
