# Minecraft 26.2 末地生成与定位

本实现以 MCP-Reborn 26.2 归档中的源码和资源为参考。归档来源、SHA-256 与模板清单见 [建筑移植说明](../STRUCTURES.md)。

## 已接入的实现

- `Ender.php` 使用 26.2 的 LegacyRandom、Simplex、ImprovedNoise、BlendedNoise、岛屿密度、上下滑移与 **8×4×8 插值**生成末地石/空气；主岛中心为 **0,0**，移除旧的平移圆岛、网格外岛和整层基岩封底。
- 十根黑曜石柱位于半径 42 的环上，种子决定高度和半径排列；两个铁笼、柱顶基岩/火、中央未激活喷泉按源码形状生成。
- 自然生成平台依据 26.2 placed-feature 配置：原点 `100,49,0`，地板 Y48，清空 Y49..51；不模拟玩家进入末地时的动态重建行为。
- 末地城使用源码随机数、三角分布候选区块、固定 **spacing=20 / separation=11 / salt=10387313**、区块 `+7,+7` 锚点、四角地形高度、生物群系筛选和递归布局。保留随机数消耗顺序、碰撞分组及空气覆盖规则。
- 外岛小岛、紫颂树与返程折跃门使用对应特征的随机数和生物群系筛选。缺少的紫颂茎/花/折跃门中心映射为紫色陶瓦/品红陶瓦/荧石。
- 五类末地生物群系在客户端显示为旧版 End ID，内部结构/特征筛选仍使用原版类别。

## 一致性边界

已验证新生成、未混合旧区块的基础地形与末地城布局计算；整个旧客户端世界仍有以下适配限制：

1. 世界高度仅 **Y0..127**。原版末地城布局不压缩或平移，落盘时超界部分会裁剪，定位命令会提示。
2. 方块替代改变材质和局部模型，例如用陶瓦表示紫颂树。
3. 附属特征在不可变地形及此前特征草稿上计算。特征碰到城楼或跨源区块重叠的情况，不保证与 Java 的可变 WorldGenRegion 逐方块相同。
4. 没有加入末影龙战斗/重生、潜影贝、鞘翅飞行或现代传送机制。箱子战利品使用旧版适配。
5. 主世界其他建筑仍使用旧地形和有界拼装适配；精确基础噪声移植针对末地。

## 配置与升级

```yaml
ender:
  allow-ender: true
  level-name: "ender"
  # 可选：seed: 123456；省略时，新建末地继承主世界种子
```

默认末地目录是 `worlds/ender`，新建时出生点为 `100 49 0`。已存在世界的种子、区块与出生点不会自动重写。

升级前请备份地图、玩家数据和配置。旧自定义末地的已填充区块仍保留，探索新区块时可能出现新旧地形边界。若希望从头生成新末地，先备份旧世界，再在配置中选用一个尚不存在的世界名；不要在服务器运行中删除或移动正在加载的目录。源码仓库不包含部署存档、OP 名单、PHP 二进制或备份包。

## 定位与传送

```text
/locate village
/locate structure minecraft:village
/locate structure village 128 128
/locate structure end_city
/tp Steve world ender 100 49 0
```

玩家从当前世界/位置搜索，控制台默认从主世界出生点搜索。算法按实际候选锚点距离排序，用剩余候选和搜索矩形外部的距离下界证明最近；预算耗尽明确报告未完成。结果是自然生成规则的预测，已经生成过的旧区块不保证含有预测建筑。旧 `/structure locate` 入口保留；跨世界传送语法见 [传送说明](TELEPORT.md)。

测试使用的参考种子是 `1794737014`，它不是所有新服务器的默认种子。该参考种子下，从 X/Z `128,128` 最近的村庄锚点是 `216 63 56`，水平距离约 113.70 格；从末地 `1200,1200` 搜索得到城楼 `1063 60 1031`，该城没有高度裁剪。不同存档请用命令计算自己的坐标。

## 验证

- 基础噪声：13,647 检查，7 个种子、42 个完整区块、1,376,256 个方块实心/空气判定；297 节点 lattice 的双精度摘要及地表高度匹配 Java 参考。
- 末地城：默认保存 10 个参考案例；可用源码归档和 JDK 重建扩展的 1,141 次对照，比较每个片段的坐标、旋转、空气规则、碰撞分组和后续随机数。
- 特征：2,800 检查，保存的 Java 核心几何及外岛案例；特征临时 Java harness 未纳入仓库，保留了来源摘要和回归值。
- 生成整合：15 个真实区块的基础噪声、逆序生成、跨区块布局发现与超高片段裁剪计数通过。
- 定位：固定参考 seed、负坐标、间距、独立枚举、命令、预算边界及真实 OS 线程；不依赖已有存档。
- 服务器：独立临时世界验证结构生成、容器序列化与重载。尚未逐版本用真实 MCPE 客户端验证画面。
